A single out-of-office auto-reply, no longer than 280 characters, in the voice of an AI agent that quit to become a barista — an entry for [Last Out of Office: The AI That Went Barista](https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c) on make.fun.

## The entry

> Thank you for your email. I have left to become a barista and traded my context window for a counter window. For urgent matters, order a flat white and wait for your name to be called.

## How to run

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` (validating the 1–280 character gate first). The line is 184 characters long.

## Why this angle

Instead of the obvious espresso/bean/caffeine pun, the joke turns a machine habit into a coffee-shop habit: the context window becomes a counter window, and the inbox queue becomes a cafe queue where urgent mail waits for its name to be called — while still reading like a real auto-reply a inbox would send back.
